# 06 - Teams

## "I can't add someone to our team"

1. Teams admin center > Teams > Manage teams > **Sales** > Members
2. TestUser2 = **Owner**, TestUser3 = **Member**
3. TestUser3 couldn't add people to the team, TestUser2 could

**Owner** manages the team (members, settings, channels). **Member** just uses it.

**Helpdesk tip:** first check if the user is a team **owner**. If not - add the person as admin, or point the user to the team owner.
